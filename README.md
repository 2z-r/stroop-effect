# ストループ効果ゲーム

表示された文字の「色」に合うボタンを押す、ブラウザで動く反応時間ゲームです。
全2ラウンド・各10問で、平均反応時間を秒で表示します。

- 単一の `index.html` だけで動作します（ビルド不要）
- 操作: ボタンをクリック、またはキーボードの 1〜4 キー

## ローカルで開く

`index.html` をブラウザで開くだけです。

## GitHub Pages で公開する

1. このフォルダの中身をGitHubのリポジトリにpushする
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch` にし、Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
